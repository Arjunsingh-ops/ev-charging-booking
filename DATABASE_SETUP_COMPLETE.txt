================================================================================
  SETUP METHODS AT A GLANCE
================================================================================

Method A - Manual SQL (Recommended for First-Time Setup)
─────────────────────────────────────────────────────────
Time:        5 minutes
Difficulty:  Easiest
Steps:
  1. Open Supabase Dashboard > SQL Editor
  2. Click "New Query"
  3. Copy-paste each SQL file (001, 002, 003, 004)
  4. Click Run
  5. Done!
Pros:  No environment variables needed, clear visual feedback
Cons:  Manual process

Method B - Command Line (Recommended for Development)
─────────────────────────────────────────────────────────
Time:        2 minutes
Difficulty:  Easy
Prerequisites: Node.js, .env.local with credentials
Command:     npm run setup-db
Pros:  Fully automated, single command
Cons:  Requires environment variables

Method C - Vercel Deployment (Recommended for Production)
─────────────────────────────────────────────────────────
Time:        10 minutes
Difficulty:  Medium
Prerequisites: GitHub, Vercel, environment variables set
Steps:
  1. Set environment variables in Vercel
  2. Push to GitHub
  3. Redeploy on Vercel
Pros:  Automatic, works on deployment
Cons:  Requires GitHub and Vercel

================================================================================
  ENVIRONMENT VARIABLES NEEDED
================================================================================

Required for app:
  NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
  NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...

Required for setup scripts:
  SUPABASE_SERVICE_ROLE_KEY=sbp_...

Optional but recommended:
  POSTGRES_URL=postgres://...
  SUPABASE_JWT_SECRET=your-secret

Where to find them:
  1. Go to https://app.supabase.com
  2. Select your project
  3. Settings > API
  4. Copy the URLs and keys

Where to set them:
  Local:  Create .env.local in project root
  Vercel: Dashboard > Project > Settings > Environment Variables
